# v1.3 Scope Lock

This release is intentionally limited to data safety, calendar planning, production-complete semantics, UX simplification, AI guardrails and executable QA.

Out of scope:

- unattended AI execution on calendar timers
- direct YouTube/Facebook/TikTok upload APIs
- cloud sync / multi-user accounts
- hosted secret vault
- direct provider price discovery

These can be added after the v1.3 reliability gates are green.
