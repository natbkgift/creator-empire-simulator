# Creator Empire Simulator — Product Brief

## Product statement

A local-first web application that helps a creator select niches, build Thai or English channel strategies, produce original videos, manage CapCut cost, publish consistently, learn from analytics, and operate multiple channels through a professional game layer.

The product is a **work system with game mechanics**, not a decorative game.

## Primary user outcome

Within five minutes, a user should be able to choose an idea, select Thai or English, create a channel or series blueprint, generate a practical prompt pack, and place the first video into a scheduled production workflow.

## Core loop

1. Observe a niche opportunity.
2. Select and score an idea by language and format.
3. Create or attach it to a channel blueprint.
4. Research and verify claims.
5. Generate hooks, script, storyboard, and CapCut prompt.
6. Produce, QA, schedule, and publish.
7. Enter actual analytics, time, money, and credit data.
8. Receive the next-best action.
9. Gain XP only from completed productive work.

## MVP boundary

### Included

- Local persistence
- 50 seed ideas across five categories
- Thai/English selection and comparison
- Channel portfolio and capacity warnings
- Channel blueprint generator
- Production pipeline
- Prompt Studio with Copy-to-Chat
- CapCut Standard/Director recommendation and credit ledger
- Calendar and ICS export
- Manual analytics and CSV import
- Deterministic simulator with assumptions
- Originality and policy checklist
- XP, missions, level, and achievements linked to real work
- JSON workspace import/export
- PWA shell

### Deferred until after MVP stability

- Direct YouTube/Facebook/TikTok API integrations
- Optional server-side AI execution
- Supabase sync and multi-device collaboration
- Full Phaser walking-avatar map
- Automated publishing
- Marketplace of community templates
- Advanced team permissions

## Initial portfolio defaults

- Primary channel: **History Lab**, English, Strange History & True Stories
- Experimental channel: **FlowBiz AI Minute**, Thai, AI Agents & Automation
- Backlog candidate: **Pattaya Intel**, Thai or English, Property & Travel Intelligence

## Capacity rule

Recommend one primary channel and one experimental channel. Do not block additional channels, but show impact on hours, CapCut credits, WIP, quality, and publishing consistency.
