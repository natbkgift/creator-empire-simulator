# UX v1.3.0 — Professional Light UI

Persistent navigation is reduced to five areas:

1. Today
2. Channels
3. Calendar
4. Production
5. Insights

Prompt Studio, CapCut Lab, Policy Shield, Simulator, Monetization, Backup/Recovery and Settings remain valid contextual tools, opened from the active mission or specific actions.

The default page is **Today**. Its primary action is the current Next Mission. The user should not need to decide which internal tool to open for the next production step.

## Visual principles

- Light neutral workspace with white primary surfaces
- One primary blue action color; semantic green/amber/red are reserved for status
- Restrained borders and shallow shadows instead of decorative glow
- Minimum practical text sizes for secondary information; avoid legacy 7–9px information density
- Channel + Active Video context remains visible without dominating the page
- XP/game mechanics are secondary; they do not occupy primary desktop chrome
- Cards use spacing and hierarchy before color
- Forms use white controls, clear labels and visible keyboard focus states
- Desktop content is constrained to a readable working width
- Mobile uses the same five-area hierarchy and a compact bottom navigation
- Motion is non-essential and respects reduced-motion preferences

## Information priority

Every work page should answer these questions in order:

1. What am I working on?
2. What should I do next?
3. When is it due / published?
4. Is anything blocking completion?
5. Where do I go only if I need more detail?

Contextual tools should not compete with the current mission for visual priority.
