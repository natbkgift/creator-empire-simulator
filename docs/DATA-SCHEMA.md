# Creator Empire Simulator — Data Schema v2

The exported Workspace is a JSON object with `schemaVersion: 2` and `id: "default"`.

## Workspace root

| Field | Type | Purpose |
|---|---|---|
| `ideas` | `Idea[]` | 50 seed ideas and saved state |
| `channels` | `Channel[]` | Channel portfolio and blueprints |
| `projects` | `VideoProject[]` | Video work through 17 stages |
| `sources` | `SourceRecord[]` | Research evidence and claim status |
| `prompts` | `PromptTemplate[]` | Saved Prompt versions |
| `calendarTasks` | `CalendarTask[]` | Manual tasks and generated workflow missions |
| `credits` | `CreditEntry[]` | Actual CapCut before/after ledger |
| `analytics` | `AnalyticsEntry[]` | Actual or Demo performance records |
| `policies` | `PolicyRule[]` | Editable policy registry |
| `monetization` | `MonetizationPath[]` | Revenue and lead paths |
| `simulations` | `SimulationRun[]` | Deterministic scenario history |
| `achievements` | `Achievement[]` | Productive milestones |
| `skills` | `SkillProgress` | 12 skill progression values |
| `xp`, `level`, `streak` | number | Game progression |
| `settings` | `Settings` | Capacity, locale, timezone and AI settings |
| `focus` | `FocusState` | Global Channel, Project and Mission context |

## FocusState

```ts
interface FocusState {
  mode: 'portfolio' | 'channel';
  activeChannelId?: string;
  activeProjectId?: string;
  activeTaskId?: string;
  updatedAt: string;
}
```

## WorkflowEvent

Records meaningful orchestration history:

```ts
type: 'focus'
    | 'mission-started'
    | 'mission-completed'
    | 'prompt-applied'
    | 'stage-advanced'
    | 'analytics-recorded';
```

It can also preserve previous/next status, Prompt type and Calendar task ID.

## CalendarTask additions in schema 2

## Migration

Schema 1 imports are migrated automatically:

- `schemaVersion` becomes `2`
- New Project artifact fields receive safe empty defaults
- Calendar priorities receive defaults
- Focus is derived from the Primary Channel and a live Project
- A Current Mission is ensured for every non-archived Project

Migration changes only the in-memory/imported Workspace. The source file is not overwritten unless the user exports a new backup.
